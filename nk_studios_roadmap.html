NK Studios

Roadmap Profissional de Desenvolvimento, Marketing e Publicação

FASE 0 — Fundação Mental & Técnica

  • Definir objetivo de vida: viver de desenvolvimento
  • Escolher engine principal: Unity
  • Padronizar linguagem: C#
  • Estabelecer rotina diária (horas fixas)
  • Organizar controle de versão (Git + GitHub)
Regra NK: disciplina > motivação.

FASE 1 — Ideia & Validação

  • Ideia simples, com diferencial claro
  • Definir gênero, câmera e plataforma
  • Escrever visão do jogo (1 página)
  • Pesquisar jogos similares (Steam / Mobile)
  • Validar se é possível fazer sozinho

FASE 2 — Pré-Produção

  • Criar GDD simplificado
  • Definir escopo mínimo (MVP)
  • Planejar arquitetura de código
  • Escolher assets temporários
  • Decidir uso de frameworks (ex: Corgi Engine)

FASE 3 — Protótipo Jogável

  • Movimento do personagem
  • 1 inimigo funcional
  • 1 mecânica principal
  • 1 cenário simples
  • Testar diversão antes de expandir
Checkpoint crítico: se não for divertido aqui, pare e ajuste.

FASE 4 — Produção (Vertical Slice)

  • Conteúdo fechado (níveis, inimigos, história)
  • Sistemas estáveis
  • UI funcional
  • Salvar/Carregar
  • Builds frequentes

FASE 5 — Marketing & Comunidade (Paralelo)

  • Criar identidade visual do estúdio
  • Postar progresso (Twitter, TikTok, Reddit)
  • Devlogs curtos
  • Construir wishlist (Steam)
  • Criar Discord (opcional)
Marketing começa no dia 1, não no lançamento.

FASE 6 — Polimento

  • Correção de bugs
  • Feedback visual e sonoro
  • Melhoria de performance
  • Balanceamento

FASE 7 — Publicação

  • Steam: página, trailer, tags
  • Play Store: otimização de APK/AAB
  • App Store: screenshots e descrição
  • Testes finais de build

FASE 8 — Pós-Lançamento

  • Correções rápidas
  • Atualizações pequenas
  • Análise de métricas
  • Planejamento do próximo projeto
