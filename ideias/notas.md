# nome para um alienigena

O nome dele pode não ser apenas uma palavra falada.

- o nome dele pode soar como um zumbido grave e profundo, que você sentiria vibrando no seu próprio peito antes mesmo de ouvir pelos ouvidos.
- o nome também pode carregar conceitos.
- o nome dele poderia significar uma linhagem ou uma função, algo como "Aquele que observa as marés de poeira"
